## Идея и место в курсе

Ошибка прокурора: P(E|¬H) ≠ P(¬H|E). Город из миллиона → P(вина|совпал)≈1/11 не
0.99999. LR = чувствительность / случайное совпадение (ЯВНО sens=0.98, не 1). Поиск по
базе: 1-(1-p)^N, «один на миллион» → 63%. Множественная проверка на РЕАЛЬНЫХ данных
(look-elsewhere). Ошибка защиты, зависимые улики (нельзя перемножать). Prior из контекста.
Русская линия: С. Н. Бернштейн (вероятность требует схемы испытаний). Мосты: 42/55/58/63.

## Проверка математики и данных (scripts/generate_lesson43_visuals.py)

- confusion (assert): p=1e-5, миллион → 10 случайных совпадений, P(вина|совпал)=1/11=0.091.
- database (assert): p=1e-6, N=1e6 → P(≥1)=1-e^{-1}=0.632.
- multiple: РЕАЛЬНАЯ цель (bike cnt) vs N случайных признаков; max |corr| растёт 0.024→0.087
  вдоль ожидаемого максимума под нулём. Look-elsewhere на данных.
- LR: ЯВНО sensitivity 0.98 → LR=0.98/1e-5=98000 (устранён дефект «sens=1»).
- Виджет в браузере: prior 1:1e6, LR 9.8e5 → апостериор 49% (=0.98/1.98); prior 1:100 →
  100%. Одна улика, разный prior → разный исход. Ошибок нет.
