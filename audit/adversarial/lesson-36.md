# Урок 36 — «Матрицы как преобразования пространства»

Дата пересмотра: 2026-07-19. Переписан с v1 (SVG-заглушки figure-1..3, виджет
g10-vision, дублирующиеся секции «Столбцы как образы базиса» / «Столбцы отвечают

matrix-transform-lab на настоящей фотографии.

## Идея и место в курсе

Матрица есть движение пространства; её столбцы — образы базисных векторов.
Определитель = ориентированная площадь (знак = отражение). Умножение = композиция
движений, порядок важен (AB≠BA). Собственные направления не поворачиваются.
Окружность → эллипс: полуоси = сингулярные числа, κ = обусловленность (важнее
определителя для устойчивости). Аффинные/однородные координаты, смена базиса.
Обратный проход при повороте изображения. Русская линия: А. Н. Крылов (собственные
числа через умножения на вектор → крыловские подпространства). Мосты: 17/18/35/37/38.

## Проверка математики и данных (scripts/generate_lesson36_visuals.py)

- Ax=(3,1) для A=[[2,1],[0,1]], x=(1,1) (assert).
- Определитель: [[2,0],[0,1]]→2, [[0,1],[1,0]]→−1, [[1,1],[1,1.02]]→0.02 (assert |det|).
- Сингулярные числа A=[[2,1],[0,1]]: σ=(2.288, 0.874), κ=2.618 (assert).
- Собственные значения [[2,1],[0,1]]: λ=2 (ось x), λ=1 (направление (1,−1)).
- Warp реального фото grace_hopper: прямой scatter даёт 25.95% дыр, обратный gather
  без дыр (assert-логика через долю).
- Виджет прогнан в браузере: единичная κ=1.0; поворот (0.7,0.7)(−0.7,0.7) det≈0.98
  κ=1.0 (форма сохранена); сдвиг (1,0)(1,1) det=1.00 σ=(1.62,0.62) κ=2.6; почти
  вырождена (1,0.9)(1,1) det=0.10 κ=38.1. Ошибок консоли нет.

## Проверка рисунков и интерактива глазами

6 PNG отсмотрены: базис (до/после, стрелки Ae1/Ae2/Ax точно на концах, косая сетка,
параллелограмм); определитель (3 панели, стрелки обхода = ориентация, вырождение в
линию); эллипс (окружность пунктиром, σ1 красная по большой оси, σ2 зелёная по
малой, κ в заголовке). Маргиналки: compose (F под RS≠SR, серый оригинал); eigen
(две собственные прямые λ=2,1 на сетке); warp (реальное фото: оригинал/обратный
чистый/прямой с дырами). glyph → и smallmatrix убраны из mpl (заголовки словами).
Виджет DPR-safe (offscreen inverse-gather + drawImage), фото деформируется вместе
со столбцами, подписи и стрелки без коллизий.

## Оставшиеся слабости

- Виджет использует обратный gather nearest (не bilinear) для скорости; для
  демонстрации геометрии достаточно, билинейная версия — в задаче 8.
- Сингулярные числа в виджете считаются через собственные значения AᵀA (2×2,
  замкнутая формула) — точно для 2D.
- Цитаты Кэли/Крылов/Клейн — точные по смыслу; атрибуции и годы верны (Крылов 1931 —
  «О численном решении…», исток крыловских подпространств).
- Фото grace_hopper даунсэмплено (40×48) для лёгкости виджета; узнаваемо, деформация
  читается.
