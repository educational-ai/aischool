# Урок 28 — «Свёртка: скользящее окно зрения»

Дата пересмотра: 2026-07-19. Переписан с v1 (SVG-заглушки, g10-vision) на
полноценный урок: настоящие фигуры matplotlib на реальном фото, собственный
виджет conv-arithmetic-lab.

## Идея и место в курсе

Свёртка = одно ядро, скользящее по полю. Размер выхода
n_out=floor((n+2p−k)/s)+1; дополнение (ноль vs повтор края), шаг
(прореживание). Несколько каналов: ядро охватывает C_in каналов,
params=C_out(k²C_in+1), не зависит от размера картинки; параметры≠операции.
Эквивариантность к сдвигу K*(TΔI)=TΔ(K*I) (не инвариантность). Реальные
данные: RGB-фото Хоппер (каналы, эквивариантность), спутник EuroSAT как
пример + утечка соседних участков. Русская линия: Котельников (теорема
отсчётов 1933 → пиксель как отсчёт, алиасинг). Мосты: 13/16/25/27/37.

## Проверка математики и данных (scripts/generate_lesson28_visuals.py)

- Размер выхода (k=3, n=32): p1s1→32, p0s1→30, s2→16 (assert). Упражнение
  7×7,k3,p1,s2→4.
- params RGB 3→16 k3 = 16·(27+1) = 448 (assert). FLOPs 32×32 3→16 k3 = 442368.
- Эквивариантность: |conv(shift(I))−shift(conv(I))| = 0.0000 в внутренней
  области (assert <1e-6) на реальном фото, сдвиг 60 пикс.
- Виджет прогнан в браузере: k3s1p1 → 52→52 (сохранён), s2 → 26×31, p0 → 25×30,
  формула подставляется вживую. Карта откликов грубеет при шаге 2. Ошибок нет.
