# Урок 22 — «Градиент: стрелка вниз по склону»

Дата пересмотра: 2026-07-19. Переписан с генераторного каркаса (1463
слова) в полноценный урок модуля «Нейрон и оптимизация».

## Идея и место в курсе

Как найти дно поверхности потерь, ощупывая её только локально.
Производная 1D → частные производные → градиент (вектор наискорейшего
роста), −∇L = наискорейший спуск, ⟂ линиям уровня, гаснет у дна.
Правило спуска $w\leftarrow w-\eta\nabla L$. Скорость обучения между
вялостью и срывом (эхо порога устойчивости урока 14). Приземление:
спуск по реальной MSE-чаше Gapminder-2007, из плохого старта к оптимуму
$w_1=0{,}809$ (та же корреляция, что у Хебба в уроке 14) за 40 шагов;
η=1,05 расходится. Русская линия: Поляк (тяжёлый шарик 1964), Нестеров
(ускорение 1983), Шор. Мосты: 14/17/20/21/24.

## Проверка математики и данных (scripts/generate_lesson22_visuals.py)

- Gapminder-2007 стандартиз.: MSE минимум w0=0, w1=0,809 (=корреляция);
  спуск из (1,5;−1), η=0,3, 40 шагов → assert w1≈0,809, loss 0,3456.
- Скорость обучения: η=0,05/0,4/0,9 сходятся, η=1,02/1,05 расходится
  (в виджете η=1,08 «взорвалась»). Порог связан с 2/λmax.
- $\nabla(w_1^2+3w_2^2)=(2w_1,6w_2)$; $(2,1)\to(4,6)$ — упражнение.
- Множитель $(1-2\eta)$ для $w^2$: сходимость 0<η<1, пороги 0,5 и 1 —
  упражнение, связь с порогами регулятора урока 14.
- Крутизна по направлениям: $\|\nabla\|=5$ для (3,4) — упражнение.
