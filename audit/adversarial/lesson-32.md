# Урок 32 — «Честная проверка: train, validation, test»

Дата пересмотра: 2026-07-19. Переписан с v1 (SVG-заглушки, g10-vision) на
полноценный урок методологии: настоящая кривая переобучения на реальных
цифрах, собственный виджет overfitting-lab. Лагутин-стиль.

## Идея и место в курсе

Заучить ≠ понять. Кривая переобучения (train↑ к 100%, test плато 82%,
разрыв растёт). Три роли: train/val/test + запрещённая стрелка (утечка).
Кривая обучения (данные важнее хитрости). Утечка: групповой разрез
(пациенты), время (train раньше test), признак с ответом. Кросс-валидация.
Двойной спуск (референс fmin.xyz). Русская линия: Вапник-Червоненкис
(VC-теория обобщения, bound test ≲ train + √(d/n)), Колмогоров (простота
описания). Мосты: 23/25/30/31.

  g10-neuron/g10-vision запрещены.

## Проверка математики и данных (scripts/generate_lesson32_visuals.py)

- Данные: sklearn digits (переобучение дерева), seed 32.

  Вердикты меняются корректно. Ошибок страницы нет.

## Оставшиеся слабости

- Кривая обучения слегка немонотонна (шум малых выборок) — честно, реальные
  данные.
- Двойной спуск — схема (не из прогона огромной сети), помечена как явление
  по литературе; классические кривые из реальных данных.
- Цитаты Фейнмана/Вапника-Червоненкиса/Колмогорова — точные по смыслу;
  атрибуции и годы верны. VC-bound дан схематично (∼√(d/n)), без констант.
