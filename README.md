# Контур

Интерактивный учебник по искусственному интеллекту для 10–11 классов:
40 уроков в 10 классе и 50 уроков в 11 классе.

Текст уроков отделён от интерфейса и хранится в Markdown. Каждый конспект
устроен как большая самостоятельная статья: не менее 1500 слов, формулы,
определения, боковые авторские заметки, три статических рисунка, собственный
интерактив и пять полностью сформулированных задач с баллами.

## Локальный запуск

Нужен Node.js версии `22.13.0` или новее.

```bash
npm install
npm run dev
```

Сайт откроется по адресу `http://localhost:3000`.

## Проверка

```bash
npm test
```

Команда собирает приложение, проверяет все 90 конспектов, 270 уникальных
рисунков, 90 интерактивных builders, обратные ссылки и редакторские
ограничения. Отдельный `npm run anti-ai` запускает проверку на шаблонные
формулировки.

## Структура

- `content/lessons/` — Markdown-конспекты;
- `lib/course.ts` — программа и метаданные уроков;
- `lib/articles.ts` — явная карта конспектов;
- `public/interactive/core.js` — маленькое ядро интерактивов без зависимостей;
- `public/interactive/widgets/` — визуализации по темам;
- `app/components/` — статья, навигация и каталог;
- `scripts/anti-ai-audit.mjs` — редакторский anti-AI-Slope-аудит.
